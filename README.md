# 2000s iPod Classic Nostalgia Web Experience

A nostalgic 2000s single-page web application featuring a photorealistic CSS iPod Classic, interactive Click Wheel, 3D Cover Flow, Web Audio API click sound effects, and YouTube playlist audio synchronization.

## Features

- **Photorealistic 3D CSS iPod Classic**: Brushed silver aluminum body, top Hold switch, 3.5mm headphone jack with interactive earbud cord.
- **Multi-Screen LCD Display**: Now Playing view, 3D Cover Flow, Menu list, "Do Not Disconnect" sync screen, and an interactive LCD Brick Break game.
- **Interactive Click Wheel**: Touch/drag rotation gesture around the wheel rim with Web Audio API click feedback.
- **YouTube Playlist API Integration**: Dynamically loads songs, titles, artists, and thumbnails from YouTube playlist `PLiU9llEoc-uWbcLZb0N7f9_duMz3-gv6w`.
- **Custom Themes**: Silhouette Vibe (wavy white earbud wire canvas background), Retro Studio Vibe, and Midnight Ambient.

## How to Host / Publish

### 1. Netlify Drop (Instant Drag & Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this project folder (`AG PROJECT`) onto the page.
3. Your site will be live instantly with a free `.netlify.app` URL!

### 2. GitHub Pages
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - 2000s iPod Nostalgia site"
   git remote add origin https://github.com/YOUR_USERNAME/ipod-nostalgia.git
   git push -u origin main
   ```
2. Go to **Repository Settings** -> **Pages** -> Select `main` branch and `/ (root)` folder -> Click **Save**.

### 3. Vercel
1. Go to [Vercel](https://vercel.com/new).
2. Import your GitHub repository or drag and drop the folder to deploy instantly.
